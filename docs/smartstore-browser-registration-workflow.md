# 스마트스토어 브라우저 등록 준비 워크플로우

## 목적
이 MVP는 도매꾹 상품 링크/HTML에서 상품 정보를 추출한 뒤, 스마트스토어 API로 바로 등록하지 않는다. 사용자가 네이버 스마트스토어 판매자센터 브라우저 화면에 직접 접속해 붙여넣을 수 있도록 자료를 정리하고, `저장하기` 또는 `임시저장` 직전 검수 단계에서 멈추는 것을 목표로 한다.

## 안전 경계
- 네이버 로그인, CAPTCHA, OTP, 계정 인증은 사용자가 직접 처리한다.
- 자동화가 있더라도 `저장하기`, `임시저장`, 최종 등록 버튼은 누르지 않는다.
- 상품정보제공고시, 인증, 카테고리, 배송/반품/A/S는 사람 검수 후 확정한다.
- 이미지 사용권, 외부 링크, http 이미지, 개인정보성 문구는 등록 전 확인한다.

## 판매자센터 입력 순서
1. 상품 기본정보
   - 상품명
   - 카테고리
   - 판매상태
   - 원산지
2. 가격/재고
   - 판매가
   - 재고수량
   - 최소주문수량 참고
   - 옵션이 있으면 옵션 구조 확인
3. 상품이미지/동영상
   - 대표이미지 1개
   - 추가이미지 최대 9개
   - 권장 1000x1000, 최소 300x300 기준 확인
4. 상세설명
   - HTML 작성 또는 에디터 붙여넣기
   - 상세이미지 깨짐 여부 확인
   - 외부링크/http 이미지/스크립트 제거 여부 확인
5. 상품 주요정보 / 상품정보제공고시
   - 상품군 선택
   - 필수 고시값 입력
   - KC/어린이/전기용품/식품 등 인증 대상 여부 확인
6. 배송
   - 배송비 정책
   - 택배사
   - 제주/도서산간 추가비
7. 반품/교환
   - 반품지
   - 반품비
   - 교환비
   - 공급사 반품 조건 확인
8. A/S, 특이사항
   - A/S 연락처
   - 상품별 특이 조건
9. 검색설정 / 판매자 코드 / 노출 채널
   - 검색 키워드
   - 판매자 관리 코드
   - 노출 채널 검수
10. 미리보기
   - PC/모바일 상세설명 확인
   - 저장 전 최종 체크

## 앱 화면에서 제공해야 하는 자료
- 브라우저 등록 준비 상태: READY / NEED_REVIEW / BLOCKED
- 복사 가능한 브라우저 입력 패키지
- 스마트스토어 입력 위치 기준 표
  - 상품명
  - 카테고리 힌트/leafCategoryId
  - 판매가
  - 재고
  - 대표이미지 URL
  - 상세 HTML
  - 원산지
  - 인증정보
  - 상품정보제공고시
  - 배송 정책
  - 반품/교환/A/S
- 저장 직전 최종 확인 체크리스트
- 상세 HTML 미리보기와 소스
- 원천 분석 JSON은 개발/디버깅용으로만 하단에 둔다.

## 저장 직전 중지 조건
다음 중 하나라도 미확정이면 저장하지 않는다.

- 카테고리를 스마트스토어 화면에서 직접 선택하지 않았다.
- 상품명 금칙어/과장 표현/100자 제한을 확인하지 않았다.
- 판매가에 공급가, 배송비, 수수료, 광고비, 부가세, 목표마진을 반영하지 않았다.
- 대표이미지와 상세이미지 사용 권한이 불명확하다.
- 상품정보제공고시 상품군/필수 항목이 비어 있다.
- 인증 대상 여부가 불명확하다.
- 배송비, 택배사, 반품지, 반품비, 교환비, A/S 연락처가 비어 있다.
- 미리보기에서 모바일 상세설명/이미지 깨짐을 확인하지 않았다.

## 향후 브라우저 자동입력 설계
수동 등록이 안정화된 뒤에는 Windows Chrome CDP 기반으로 `저장 직전`까지 자동 입력을 확장할 수 있다.

권장 어댑터:
- CategoryAdapter
- BasicInfoAdapter
- PriceStockAdapter
- MediaAdapter
- DescriptionAdapter
- ProductInfoNoticeAdapter
- ShippingAdapter
- ReturnExchangeAdapter
- ExposureAdapter

자동화 완료 지점은 `미리보기` 또는 `저장하기 버튼이 보이는 상태`이며, 실제 저장은 사용자의 명시 승인 후에만 가능하다.
